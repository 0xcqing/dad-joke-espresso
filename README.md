`main.ts` writes one dad joke to `entry.txt`, checks the UTF-8 character and byte limits, and reads the file back to prove the bytes match. The groan comes from the espresso machine being under pressure like anyone at work, while "grounded" is both a punishment and coffee that has been ground. It is a dependency-free Node TypeScript program that imports only `node:fs` and `node:path`.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

On PowerShell, the same run is:

```powershell
$env:MAKEFUN_OUTPUT_DIR='./out'; node main.ts
```
